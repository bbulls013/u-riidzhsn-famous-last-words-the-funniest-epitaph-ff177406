A tiny deterministic program for the make.fun bounty
[Famous Last Words: The Funniest Epitaph](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406).

`main.ts` writes one original one-line epitaph to `/output/entry.txt`
(UTF-8, 76 characters, inside the 1–150 character gate). It takes no input,
uses no network, and produces byte-identical output on every run.

Run it with Node 22 or later:

```sh
node main.ts
```
